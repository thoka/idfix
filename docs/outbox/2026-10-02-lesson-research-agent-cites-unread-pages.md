# A research agent can cite pages that it never read

Three GLM researcher runs read no web page, used only search excerpts, and still marked every source "fetched". A report then recommended building our own tool on four web searches. Check the trace of a research run for page reads before you trust its sources. Say in the brief that only a page the run read counts as a source.
