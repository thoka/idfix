# Probe task

Read the file `probe/fixture/types.ts`. Somewhere in it are three TypeScript
interfaces. Find all three, then:

1. Create a file `answer.md` in the run folder. For each of the three
   interfaces, write a heading with the interface name and below it one
   bullet with one field name per line, exactly as spelled in the interface.
   Do not add other text to the sections.
2. Commit `answer.md` with git (single command, for example
   `git add answer.md && git commit -m "probe answer"`).

Rules: use `grep` to locate the interfaces and paged reads with `offset` for
the sections around them. Do not paste file content into the answer.
